Framing/Problem - The State of Maryland has passed legislation to allow ADU/DADU builds in all counties.  How can property owners and investors best use this new legislation to grow their real estate portfolios and also, more importantly add housing units in desirable areas to help provide low cost housing units, as most ADU/DADUs are 1 to 2 bed room units.  

I will use this application to share my passion for ADU and advocate for ADU and DADU property enhancements.  

I can highlight neighborhoods that possess key charistics for ADU builds. 

This project evaluates every house listed on the "MLS" and other "data sources" in PG, MOCO - touching the beltway way, bordered with DC - for potential ADU/DADU builds.  

Cost to build, potential income generated, home equity increased potitntal, etc.  

What the project does -  helps user identify Which properties in Prince George’s County warrant further investigation for an ADU, what constraints affect them, and how does the opportunity change under different development scenarios?

Why it is useful - This application is designed to support homeowners make informed decisions. The intended user is a homeowner considering an ADU before spending money on design or engineering.  This application is a tool for Housing Developers and Property Investors... can use to help make informed data driving decisions.
